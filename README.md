# TurnVK

Клиент для серверов WDTT: WireGuard поверх DTLS через TURN-серверы звонков VK. Совместим со стандартным сервером WDTT и со встроенным сервером [wdtt-router](https://github.com/Jetvac/wdtt-router); принимает те же ссылки `wdtt://`.

Платформы: Android (приложение) и Windows (сейчас — консольный клиент с SOCKS5-прокси, дальше — полноценный VPN с окном). Ядро одно на все платформы.

## Как это работает

```
приложение ─► WireGuard (в процессе) ─► сессии ─► TURN VK ─► сервер WDTT ─► интернет
                                         │
                                         └─ каждая сессия: UDP-сокет → выделение на TURN VK →
                                            RTP-маскировка (ChaCha20-Poly1305) → DTLS 1.2 → GETCONF
```

1. По ссылке звонка VK клиент заходит в звонок анонимным гостем (как веб-клиент VK Звонков) и получает учётные данные TURN.
2. Открывает несколько сессий, каждую — через своё выделение (allocation) на TURN-сервере VK. Через первую получает от сервера конфигурацию WireGuard.
3. WireGuard работает внутри процесса и передаёт пакеты прямо в сессии, без локального UDP-порта.

## Чем отличается от исходного клиента

| | Исходный клиент | TurnVK |
| --- | --- | --- |
| Путь пакета | WireGuard-приложение → UDP 127.0.0.1:9000 → отдельный процесс клиента → сессии | WireGuard и сессии в одном процессе, без локального сокета и лишних копий |
| Распределение по сессиям | по 12 пакетов на сессию по кругу | так же порциями (16), но слабо загруженный туннель идёт через одну сессию — меньше переупорядочивания |
| Перезапуск сервера | клиент ждёт до 30 минут (таймаут чтения) или 90 с до перезапуска сторожем; потом ещё ~16 с на рукопожатие WireGuard | закрытие сессий сервером замечается сразу, сброс устаревшей сессии — по первому пакету; рукопожатие WireGuard — сразу, без ожидания таймаута |
| Сервер замолчал без сброса | — | переподключение через 8 с, если пакеты уходят, а ответа нет |
| Смена сети (Wi-Fi ↔ LTE) | ждёт, пока сессии отвалятся | сессии переоткрываются сразу |
| Учётные данные VK | группа из 9 сессий на набор | группа из 8 сессий на набор (VK ограничивает число выделений на набор) |
| Капча VK | автоматический обход (подделка отпечатка браузера, решение головоломки, автонажатие) | капча показывается пользователю; после проверки подключение продолжается само |
| MTU | не ниже 1280, даже если сервер прислал меньше | берётся из конфигурации сервера |

## Замеры

Windows, домашний интернет, реальные TURN-серверы VK, тестовый сервер wdtt-router (1 vCPU), выход через второй сервер:

- подключение — 1,2–1,5 с, первый запрос — около 0,2 с;
- скачивание 50 МБ: 16 сессий — 23,6 Мбит/с, 24 сессии — 31,0 Мбит/с;
- плановый перезапуск сервера — теряется один запрос, который был в пути; аварийное завершение сервера (SIGKILL) — туннель восстанавливается примерно через 2 с после запуска сервера.

## Сборка

Ядро и консольный клиент:

```bash
go test ./...
go build -o turnvk.exe ./cmd/turnvk
```

Android (нужны Android SDK, NDK, JDK 17, Gradle 8.11):

```bash
go install golang.org/x/mobile/cmd/gomobile@latest
gomobile init
gomobile bind -target=android -androidapi 24 -o android/app/libs/turnvk.aar ./mobile
gradle -p android assembleRelease
```

GitHub Actions собирает всё это при каждом push: APK и `turnvk.exe` — в артефактах сборки.

## Консольный клиент (Windows, Linux, macOS)

```bash
turnvk -link "wdtt://…"                 # SOCKS5-прокси на 127.0.0.1:1080
turnvk -link "wdtt://…" -test           # проверить туннель (IP выхода, DNS) и выйти
turnvk -link "wdtt://…" -download URL   # замер скорости
```

Флаги: `-sessions` (по умолчанию 16), `-obfs audio|video`, `-device-id`, `-turn host:port`, `-dns`. Если VK просит капчу, на Windows открывается окно с ней (WebView2).

## Устройство кода

| Пакет | Что делает |
| --- | --- |
| `core/link` | разбор ссылок `wdtt://` |
| `core/wrap` | RTP-маскировка (формат сервера WDTT) |
| `core/vkcreds` | учётные данные TURN из звонка VK, капча через интерфейс `CaptchaSolver` |
| `core/session` | одна сессия: TURN → маскировка → DTLS → GETCONF, распознавание сброса от сервера |
| `core/engine` | пул сессий, WireGuard в процессе, переподключение, сторож |
| `core/netx` | сокеты в обход туннеля (на Android — `VpnService.protect`) |
| `mobile` | API для Android (gomobile) |
| `cmd/turnvk` | консольный клиент |
| `android/` | приложение: VpnService, экран, капча |
